# EGB320 Search and Rescue Robot

Team 4's autonomous search-and-rescue robot for the EGB320 Robot Design Challenge (Semester 2, 2026).

## Structure

- System/Navigation - exploration, path planning, state machine
- System/Vision - camera-based marker/victim detection
- System/Mobility - motor control, drivetrain
- System/Rescue - victim collection mechanism
- System/Robot Code - misc scripts, tests, calibration tools
